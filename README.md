# Sales Performance Analysis using Tableau

## 📌 Project Overview

This project analyzes sales transaction data using Tableau to identify
regional sales performance, customer-segment profitability, monthly
order trends, and the relationship between sales and profit.

## 🎯 Business Objectives

- Analyze regional sales performance
- Identify profitable customer segments
- Analyze monthly order trends
- Compare sales and profitability
- Identify high-sales but low-profit customers
- Build an interactive Tableau dashboard

## 🗂 Dataset

- 8,399 records
- 23 attributes
- Sales transactions
- Customer information
- Product information
- Regional information
- Order and shipping information

## 🛠 Tools Used

- Tableau
- Microsoft Excel
- Data Visualization
- Calculated Fields
- Interactive Filters

## 🔍 Key Insights

- Central region contributed 31.51% of total sales.
- West contributed 24.47%.
- May recorded the highest order quantity.
- November recorded the lowest order quantity.
- Central generated the highest total profit.
- Higher sales generally corresponded with higher profit,
  but several high-sales records had relatively low profitability.

## 💡 Business Recommendations

- Investigate low-margin/high-sales customers.
- Analyze regional profitability separately from sales.
- Optimize inventory around high-demand months.
- Investigate customer segments driving regional profitability.
- Monitor discounts and their impact on profit margins.
